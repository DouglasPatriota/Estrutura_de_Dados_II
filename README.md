# Estrutura de Dados II (UDF)

Implementações práticas e atividades desenvolvidas na disciplina de Estruturas de Dados II na Universidade do Distrito Federal (UDF).

## 📁 Mapeamento do Repositório

- **`RevisãoEstruturaDadosI/`**: Atividades de revisão em linguagem **C** (alocação dinâmica de memória com `malloc` e `free`, ponteiros e estruturas).
- **`AULA_2/`**: Conjunto de **10 exercícios práticos em Java** abordando conceitos fundamentais de POO, vetores e manipulação de objetos.
- **`AULA 3/`**: Exercícios e desafios práticos desenvolvidos na Aula 3.
- **`Estrutura_dados_Avancados/`**: Algoritmos e estruturas avançadas (árvores binárias, balanceamento e alocação dinâmica).
- **`Serious_games/`**: Aplicação de estruturas de dados e travessia de árvores binárias em jogos educativos em C++.
- **`Grafos/`**: Implementações de algoritmos em grafos, incluindo **Busca em Largura (BFS)** e **Busca em Profundidade (DFS)**.

---

## ☕ Destaque: 10 Exercícios em Java (`AULA_2/`)

A pasta `AULA_2/` contém 10 exercícios práticos focados em consolidação de sintaxe e lógica em Java:
1. Exercícios de manipulação de vetores e matrizes.
2. Controle de fluxo e estruturas de repetição.
3. Criação e manipulação de objetos e classes.

### 🚀 Como Compilar e Executar os Exercícios em Java

Para compilar e executar qualquer um dos exercícios Java presentes em `AULA_2/`:

```bash
# 1. Navegue até a pasta AULA_2
cd AULA_2

# 2. Compile o arquivo desejado (exemplo: Exercicio1.java)
javac Exercicio1.java

# 3. Execute o programa compilado
java Exercicio1
```
